# 演示视频脚本

> 需要两条视频，作用不同，别混在一起录：
> **A. 产品演示**（90–120 秒）— 证明东西能用
> **B. AI 协同过程**（3–5 分钟）— 证明过程可复现，这是赛道硬性要求

---

## 录制前 Checklist

- [ ] 关掉 `.env` 窗口、任何显示 API Key 的界面（**Key 泄露 = 直接违规**）
- [ ] 关掉微信 / QQ / 邮箱通知
- [ ] 浏览器开无痕窗口，只留一个标签页（收藏栏也关掉）
- [ ] 分辨率 1920×1080，缩放 100%
- [ ] 提前跑一遍，确认 `npm run dev` 正常、`.env` 里 `USE_MOCK=false`
- [ ] 麦克风试音（有旁白比纯字幕分高）
- [ ] 鼠标移动放慢，点完停 1 秒再动

| 用途 | 工具 |
|---|---|
| 录屏 | `Win + G`（自带，够用）或 OBS |

## A. 产品演示（90–120 秒）

### 分镜表

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–10s | 满屏微信群消息截图/录屏（找几张杂乱的通知截图快速划过） | 「大学生找比赛，信息散在群里、公众号、官网，口径还经常对不上。」 |
| 10–20s | 切到工具首屏，鼠标划过三栏布局 | 「这个工具把这段流程做成一条可视化的 AI 工作流。」 |
| 20–45s | 点「**可疑赛事**」→ 开始分析 → 四节点依次点亮 → 右侧红牌 | 「先看一个诈骗赛事。四个 Agent 依次抽取信息、核查风险、评估匹配、规划备赛。」 |
| 45–55s | 鼠标指向风险标签「出现高风险话术」+ 核验步骤 | 「它不说『这是假的』，而是告诉你『哪里可疑、去哪核实』。」 |
| 55–80s | 点「**公众号推文**」→ 分析 → 绿色通过 → 四维打分条 | 「换成正规赛事：白名单命中、官网域名核对通过，四维打分显示技能匹配 85、时间充裕 80。」 |
| 80–95s | 点「**无效内容**」→ 显示「未识别出赛事」 | 「喂一段食堂涨价的消息，它不会硬凑一个赛事出来——这是防幻觉设计。」 |
| 95–110s | 打开 `eval/report.md`，快速划过表格 | 「12 条评测用例，覆盖诈骗、过期、冲突、提示注入，逐项可回归。」 |
| 110–120s | 回到首屏 | 「赛博赛事雷达：不是告诉你有什么比赛，而是告诉你这个比赛值不值得去。」 |

### 拍摄要点

1. **诈骗案例放最前面**——红色视觉冲击最强，10 秒内抓住注意力。
2. 每个案例点完，**等进度条走完再切**，别剪掉过程（过程本身就是卖点）。
3. 鼠标不要抖动，点击后停顿 1 秒。
4. 旁白说人话，不要念技术名词。

## B. AI 协同过程（3–5 分钟，硬性要求）

> 这一条决定「过程可复现」的分数。评委要看的是**你怎么指挥 AI**，不是成品。

### 分镜表

| 时间 | 画面 | 关键动作 |
|---|---|---|
| 0–30s | 打开 AI 对话窗口，输入第一段需求 | 展示你**先说明目标用户和约束**，而不是上来就让 AI 写代码 |
| 30–70s | AI 给出目录结构和文件清单，你逐条确认/修改 | 展示你在**review 结构**，说「这个不用，那个拆开」 |
| 70–130s | AI 写后端 SSE 代码，跑起来没数据显示 | **重点镜头**：你说「一条事件都没推出来」，让 AI 排查 |
| 130–190s | 定位到 `req.on('close')` 的问题，改成 `res.on('close')` | **最高分镜头**：你能说清为什么错——「请求体读完就触发 close，正常请求被当成断开」 |
| 190–250s | 让 AI 加「证据校验」，你要求「evidence 必须在原文逐字找到」 | 展示你在**定义反幻觉标准**，不是让 AI 自己决定 |
| 250–310s | 评测跑出 10/12，两条失败，你判断哪条是测试数据错 | **次高分镜头**：区分「系统错了」和「我的用例错了」 |
| 310–360s | 打开 GitHub 提交历史 | 「每完成一块就提交一次，历史能看出开发路径」 |

### 旁白要点

- 「我通常先让它说明方案，确认后再动手，避免它一次写太多我看不过来。」
- 「这里它写错了，但语法和 lint 都过——只有跑起来才暴露。」（**这句话很值钱**）
- 「我要求它每个字段都要有原文出处，找不到就不许填。」
- 「这条是我测试用例写错了，不是系统的问题。」

### 常见错误（别犯）

| 错误 | 后果 |
|---|---|
| 全程「AI 一次就写对了」 | 评委怀疑造假 |
| 只录成品演示，没有对话过程 | 过程可复现项直接丢分 |
| 四倍速播放，看不清在做什么 | 等于没录 |
| 画面里露出 API Key | 违规 |
| 视频超过 100 MB | GitHub 传不上去 |

## 一句话记住的重点

> 评委不看你做得多漂亮，看你**遇到问题时怎么想**。
> 所以：**保留失败、展示修正、说清依据。**
