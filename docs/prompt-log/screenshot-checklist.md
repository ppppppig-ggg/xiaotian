## 1. 需要哪几张

| 序号 | 迭代 | 在 AI 工具里搜什么 | 必须拍到什么 |
|---|---|---|---|
| 1 | SSE 零事件 | `SSE`、`req.on('close')`、`一个事件都没有` | 你的提问 + AI 第一次给的错误方向 + 你指出 curl 直连也没事件 + AI 的修正 |
| 2 | 风险与匹配打架 | `红牌`、`不建议`、`覆盖` | 你提出矛盾 + AI 建议改 Prompt + 你否决并说明要写进代码 |
| 3 | 防幻觉置空打错路径 | `setPath`、`registration.deadline`、`置空` | AI 先说逻辑正确 + 你追问路径不存在会怎样 + AI 承认 + 修法 |

一次截图拍不全时，同一条迭代可以拍 2–3 张，用 `-1`、`-2` 后缀区分。

## 2. 命名与位置

```
docs/prompt-log/
├── iteration-1-sse.png（或 -1.png / -2.png）
├── iteration-2-risk.png
└── iteration-3-validate.png
```

要求：

- 截图里**必须同时看到你的提问和 AI 的回答**，只截结论无效。
- 遮掉 API Key、手机号、其他无关窗口。
- 不要美化成只有成功结果的「精选集」——保留被推翻的方案更能说明判断力。

## 5. 如果实在找不到原始对话

不要伪造。保留重建稿里的说明，并在答辩时主动说明：

> 「原始对话工具已不可回溯，这份是按提交记录重建的，每条都能对应到具体 commit 和测试。」
