## 必交材料

### 1. 代码仓库与演进记录

- [ ] 确认 GitHub 仓库为公开，或为评委提供访问权限。
- [ ] 检查提交历史保留多个功能级提交，禁止用一个 `initial commit` 覆盖完整开发。
- [ ] 核对 `.env`、API Key、个人群聊内容没有进入仓库。
- [ ] README 中的启动方法、评测数字和当前代码一致。

### 2. Prompt 历史快照

- [x] 已重建三次核心迭代的交互过程：`docs/prompt-log/prompt-chain.md`（明确标注为重建稿）。
- [ ] 从实际 AI 工具补导原始对话或未篡改截图，按 `iteration-1-sse.png` 等命名放入同目录。
- [ ] 每份包含人类 Prompt、AI 建议、人工修改意见、AI 后续答复和代码落地证据（重建稿已按此结构组织）。
- [ ] 若确实无法取得原始导出，保留重建稿的「材料性质说明」，不要删除或伪装成原始记录。
- [ ] 不要把 `process-log.md` 的回顾摘要当作完整对话导出。

### 3. 10 分钟极速复现指南

- [ ] 从干净目录执行 `git clone`、`npm ci`、`npm run dev`。

- [ ] 按指南检查健康状态、导出报告和故障排查说明。

### 4. 演示视频与技术文档

- [x] 提交 `output/pdf/campusrace-technical-design.pdf`；当前 18 页，未超过 30 页。
